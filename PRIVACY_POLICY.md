# Privacy Policy – اوقاتِ نماز (Awqat-e-Namaz)

**Last updated: 17 November 2026**

## Information and location
The app calculates prayer times locally on the user's device. If the user taps “میرا مقام استعمال کریں”, the app requests approximate location access and reads an available recent device location to calculate prayer times. The location is not transmitted to a server or shared by this app. The app does not include advertising, analytics, or user accounts in this project version.

## Storage and deletion
The selected latitude/longitude and Asr calculation preference are stored locally on the device so the app can retain the user's settings. The user can clear this information by clearing the app's storage or uninstalling the app.
